## 關於 SpacetimeDB

SpacetimeDB 是一個將資料庫與應用伺服器合而為一的革命性平台。透過將應用邏輯直接嵌入資料庫（以「模組」形式），客戶端能直接連接資料庫，省去中間層伺服器的需要。

- **官方網站**：https://spacetimedb.com
- **官方文件**：https://spacetimedb.com/docs
- **GitHub（上游）**：https://github.com/clockworklabs/SpacetimeDB
- **Discord 社群**：https://discord.gg/spacetimedb
